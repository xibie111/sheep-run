# 主菜单参考样式 v2

本目录保存本轮使用内置 `image_gen` 分别生成的六张透明素材。完整提示词、参考图位置与生成源路径在 `generation.json`；项目 PNG 与生成源逐字节一致，原参考图及原有模块 UI PNG 未写入。

| 文件 | 用途 |
| --- | --- |
| `title-v2.png` | 正面羊头与前蹄、弧形木牌、金色“小羊快跑”、连体副牌“在牧场中 · 一路向前” |
| `start-v2.png` | 木框、浅金面板、播放图标与“开始游戏” |
| `wardrobe-v2.png` | 衣架、居中文案“衣橱”、花叶与木框 |
| `settings-v2.png` | 齿轮、木框与花叶 |
| `score-v2.png` | 完整皇冠饰牌、“最高分”与空数字区 |
| `digits-v2.png` | 0–9 粗方数字字图，用实际存档分数动态排字 |

参考图的标题是经过单字倾斜、金色渐变、深棕描边和下侧挤出处理的图形字；按钮文案是粗笔画、略不规则的中文，数字则是内孔明确的粗方块字。截图不足以确认原字体名称或获得原 TTF。本轮按可见字形与材质重做图形字，不声称找到了原字体文件，也不保证像素逐点相同。

`MenuArtLayer.ts` 在屏幕物理分辨率的独立 Canvas 绘制这组 UI，不先缩入 480×270 玩法画布。所有图片等比绘制、关闭平滑，固定文案与图标在同一素材内；数字使用上述字图单独排版，不把示例 12345 写死。界面层 `pointer-events:none`，Phaser 仍负责触摸命中、按压、移出及取消。暂停时隐藏菜单图层，恢复时显示；切场景或销毁游戏均清理图层和监听。

`geometry.json` 和 `src/data/menuArtGeometry.ts` 由 `python tools/inspect-menu-art.py` 只读测量生成。测量包含皇冠、叶片与木框的完整实色范围，并保留四源像素边缘余量；不会改写 PNG。分数牌按这个整体外框锚定安全区内，顶部与右侧各留 8 逻辑像素。触摸区域使用同一布局与尺寸。长分数等比缩小到牌内数字行。

最新屏幕、触摸、旋转和生命周期证据见 `docs/aegis/work/2026-10-09-menu-reference-ui/`。其他聊天的背景、十三款皮肤、全游戏动态文字与跑酷 HUD 更新保留；本目录仅负责主菜单参考样式。
